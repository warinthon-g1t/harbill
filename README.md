# หารบิลคืนนี้

เว็บแอปหารค่าอาหาร คาราโอเกะ และเหล้า ตามคนที่ร่วมจริง ทำเป็น PWA ติดตั้งลงหน้าจอโฮมของมือถือได้ และใช้งานได้แม้ไม่มีอินเทอร์เน็ต

- แยกหมวด อาหาร / คาราโอเกะ / เหล้า / อื่นๆ และเลือกได้ว่าใครหารรายการไหน
- หารเท่ากัน หรือหารตามชั่วโมงที่อยู่ในห้อง / ตามสัดส่วน
- รองรับหลายรอบ (คนมาสมทบทีหลังไม่ต้องจ่ายรอบแรก)
- Service charge, VAT และปัดเศษขึ้นเป็นบาท
- กดแชร์สรุปยอดไปไลน์ได้ทันที
- ข้อมูลเก็บในเครื่องของคุณเอง (localStorage) ไม่มีการส่งขึ้นเซิร์ฟเวอร์

## โครงสร้างไฟล์

```
harbill/
├── index.html             หน้าเว็บ
├── styles.css             หน้าตา (มือถือก่อน แล้วขยายเป็นจอใหญ่)
├── app.js                 ตรรกะการหารบิลทั้งหมด
├── manifest.webmanifest   ข้อมูลแอปสำหรับติดตั้งลงหน้าจอโฮม
├── sw.js                  service worker ทำให้ใช้ออฟไลน์ได้
├── icons/                 ไอคอนแอป
└── fonts/                 ฟอนต์ Manrope + Noto Sans Thai (ไลเซนส์ OFL)
```

## ขึ้น GitHub Pages

```bash
cd harbill
git init
git add .
git commit -m "หารบิลคืนนี้ v1"
git branch -M main
git remote add origin https://github.com/<username>/harbill.git
git push -u origin main
```

จากนั้นเข้า GitHub → repo `harbill` → **Settings → Pages**
- Source: **Deploy from a branch**
- Branch: **main** / **(root)** → Save

รอประมาณ 1–2 นาที จะได้ลิงก์ `https://<username>.github.io/harbill/`

## ติดตั้งลงมือถือ

**iPhone** — เปิดลิงก์ใน **Safari** → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**
**Android** — เปิดใน **Chrome** → เมนู ⋮ → **ติดตั้งแอป** (หรือ เพิ่มลงในหน้าจอหลัก)

เปิดครั้งแรกตอนมีเน็ตหนึ่งครั้ง หลังจากนั้นใช้ออฟไลน์ได้

## ทดสอบในเครื่องก่อน push

```bash
cd harbill
python3 -m http.server 8000
```

เปิด `http://localhost:8000` (service worker ไม่ทำงานถ้าเปิดไฟล์ตรง ๆ แบบ `file://`)

## เวลาแก้ไขแล้วอัปเดต

1. แก้ไฟล์ตามต้องการ
2. เปิด `sw.js` แล้วเปลี่ยน `const CACHE = 'harbill-v1'` เป็น `'harbill-v2'` (เพิ่มเลขทุกครั้ง)
3. commit แล้ว push

ถ้าไม่เปลี่ยนเลข มือถือที่ติดตั้งไว้แล้วจะยังใช้ไฟล์เดิมที่เก็บไว้ในเครื่อง
ถ้าเพิ่มไฟล์ใหม่ ให้ใส่ชื่อไฟล์ลงในรายการ `ASSETS` ใน `sw.js` ด้วย
